# 一站同行 · 需求

来源：2026-10-21 用户要求沿用本项目，提前准备部分功能，现场交给协作者完善。以下由 Codex 整理并实现基础版，待 Kiro 在可用账号中审阅。

1. 当用户带来项目或选择样例时，应能在出发前选择七站旅程或一站同行；默认七站。
2. 当选择一站同行时，必须通过真实移动、推箱和角色切换完成第一关，随后经过回忆页到站；不得自动通关或填充其余六站。
3. 在回忆页，应能使用已有整理台选择真实原件，珍藏、交接或暂存；也允许不选。没有提交时不可合成 Git 历史。
4. 到站后应能使用已有三幕仪式，选取实际留下的文件或有依据的成果，落款并保存。未完成项目的事实不应被改成完成。
5. 网页、PNG、HTML 应显示真实进度和一站同行标记；在解谜前直接到站仍应显示提前到站。
6. 回看结果中的遗物只编辑回忆，不推进第二关；重玩保持所选路线但清空当次通关和仪式；新项目恢复默认七站。
7. 桌面键盘、320/390 px 视口及减少动态模式均应可完成。短旅程只是范围选择，不设置催促玩家的倒计时。

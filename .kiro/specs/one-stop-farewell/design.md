# 一站同行 · 设计

由 Codex 编写，2026-10-21；不是 Kiro 生成记录。

使用现有七站游戏的第一关形成完整短流程：项目确认 → 雨后小径真实解谜 → 回忆/遗物整理 → 到站 → 三幕告别 → 纪念导出。首次试玩不需要网络或模型；真实 GitHub 项目可使用现有导入链路。

- `Journey.itinerary` 保存 `one` / `full`，缺失时按旧版七站处理。
- `reachedJourneyEnd` 同时检查已访问的真实关卡和路线终点，供继续与临时到站使用。
- `journeyStats` 统一网页、PNG 与离线 HTML 的统计文案，始终保留七站总数。
- `main.ts` 只在首次回忆完成且没有 `memoryReturn` 时判断路线终点。结果回看优先回原状态，避免推进关卡。
- 路线选择放在确认区，开场文字跟随选择。回忆页提示整理遗物，继续按钮明确去站台。沿用现有撤销、重开、双人、降动和仪式行为。
- 纪念图和离线回忆册保留原件、落款与真实完成情况。没有引入持久化、额外服务或计时系统。

验证对应 `tests/itinerary.test.ts` 和 `tests/itinerary-browser.mjs`；默认七站复用 `tests/play-settings.mjs`。现场增量应单独记入任务清单，避免把已有功能再次标为 Kiro 新作。
